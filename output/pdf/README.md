# Example phonebook PDFs

These Letter-size examples contain only fictional browser-demo data: Casey's
bedroom phone, Alex, Drew's mobile, and Grandma June. Grandma has shortcut 1 and
Alex has shortcut 2. They were downloaded using the shared PDF renderer in the
local demo, without the browser's print dialog. Print at 100% and trim the border.

For updated examples, reset the demo, assign Grandma June shortcut 1 on Casey's
phone, open its phonebook, and download each style on US Letter paper. Render the
PDFs with Poppler to update the matching `docs/images/phonebook-pdf-*.png` previews.
Never commit a real family's phonebook.
